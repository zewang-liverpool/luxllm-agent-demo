7. Windows自带录屏

Xbox Game Bar围绕当前应用录制，因此幻灯片、浏览器和VS Code分别录制，后期更容易拼接。

  1. 点击需要录制的应用窗口。
  2. 按Win + G打开Game Bar。
  3. 按Win + Alt + R开始录制。
  4. 静止2–3秒后再操作。
  5. 片段结尾静止2秒，再按Win + Alt + R停止。
  6. 立即播放素材，检查清晰度和完整性。

8. 本人配音、剪辑与导出

配音

  • 按7段分别录制本人英文旁白。
  • 每段开头和结尾保留约0.5秒安静部分。
  • 语速正常；放不下就删减文字，不加速音频。
  • 不使用TTS，不需要背景音乐。
  • 音量一致，无削波、喷麦、键盘声或持续噪声。

剪辑

  • 先按时间轴排列画面，再加入旁白。
  • 只使用短淡入淡出，避免花哨转场。
  • 删除加载、误点、长空白和重复操作。
  • 不能增加报告中没有支持的新结论。
