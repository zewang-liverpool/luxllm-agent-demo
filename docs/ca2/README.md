# COMP702 CA2 preparation pack

This directory contains the working materials for the COMP702 second assessment video and Q&A.

## Files prepared automatically

- `LuxLLM_Agent_CA2_Presentation.pptx` — final seven-slide deck using the current Viewer, implementation boundaries, formal evidence, limitations, and conclusion.
- `CA2_NARRATION_SCRIPT.md` — an English narration script targeting approximately 9 minutes 20 seconds, including screen actions.
- `CA2_QA_PREPARATION.md` — concise answers to likely marker questions.
- `CA2_RECORDING_AND_SUBMISSION_CHECKLIST.html` — a local interactive checklist whose ticked state is saved in the browser.
- `CA2_DETAILED_RECORDING_GUIDE.html` — a detailed Chinese workflow covering the 9:20 shot list, Viewer actions, Windows recording, voice-over, export, and final checks.
- `CA2_AUTOMATED_READINESS.md` — results of automated file, test, and evidence checks.
- `source-notes.txt` — local evidence and asset provenance used in the deck.

## Assessment constraints built into this pack

- The planned final video is under 10 minutes, with a hard rehearsal stop at 9:40.
- The opening is short; most of the video is allocated to the software demonstration and selected source code.
- The script requires narration in the student's own voice.
- The title slide states ethical category `A0`: data category A (no data derived from humans or animals) and participant category 0 (no human participants in any activity).
- The Q&A preparation assumes both markers may ask the student to open files and explain code live.

## Do not submit the existing 75-second demo as the CA2 video

`docs/demo_videos/LuxLLM_Agent_Final_Demo_Run008_Isometric_Visualization.mp4` is useful as an insert or backup clip, but it does not contain the required introduction, own-voice narration, code demonstration, empirical evidence, and ethical statement.
