# Legacy Viewer Prototype

`s3_isometric_battle_viewer.html` is the original June 2026 replay prototype.
It is retained only for development provenance and is not the current Viewer
used for CA2, dissertation evidence, or project evaluation.

Use the current player-first Viewer with the DTAV Inspector instead:

```text
docs/viewers/s3_isometric_battle_viewer_v09n12d_trace_overlay.html
```

From the repository root:

```powershell
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/docs/viewers/s3_isometric_battle_viewer_v09n12d_trace_overlay.html
```
